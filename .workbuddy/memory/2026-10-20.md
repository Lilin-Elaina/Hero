# 2026-10-20 pitch 云台 + 摩擦轮扩展方案（只给代码，用户自己改）

## 新硬件节点(用户口述)
- pitch 云台: GM6020, 驱动器拨码 ID=2 → 控制 0x1FF byte2-3, 反馈 0x206
- 摩擦轮: 2×3508+C620, 电调 ID=2/3 → 控制 0x200 byte2-3/byte4-5, 反馈 0x202/0x203
- 原底盘: 3508 ID1(左)/ID4(右) 不变; yaw 6020 ID1 不变
- 全部 CAN ID 无冲突(C620 反馈=0x200+ID 与 6020 反馈=0x204+ID 错开; 0x204=C620ID4, 0x205=6020ID1)

## 关键设计决策(讲给用户的核心)
1. **同帧合并原则**: 0x200 每ms只能发一帧——若底盘发一帧(byte2-5=0)又摩擦轮发一帧,
   ID2/ID3 电调每 ms 先后收到 0 和目标电流, 电调"最后收到的立即生效"→电机抖振。
   0x1FF 同理(yaw/pitch)。所以必须 DJ3508_Send_All(4路一帧) + DJ6020_Send_All(2路一帧)。
2. 遥控分配: 右摇杆垂直 ch[1]→pitch; 摩擦轮开关=物理右拨杆上位(s_left==RC_SW_UP)。
   依据: 用户实测 s_right↔物理左拨杆(使能在用), 故 s_left↔物理右拨杆(现在空闲)。
   DT7 纯遥控模式无键鼠输入(DR16 须插USB才有), 所以只能用拨杆。
3. pitch 有机械限位→恢复角度限位逻辑(yaw 的注释块照搬), 配 GMP_SAFE_NO_OUTPUT=1
   先量角度再出力(同 yaw 流程)。摩擦轮两轮必须反向(FRIC_SIGN 一正一负)。
4. 摩擦轮使能: online + 右拨杆上位 + FRIC_REQUIRE_ARMED(默认还要求底盘使能) + 300ms 防抖。
5. 摩擦轮电流 2A 起步(上限6A), 指令斜坡 8A/s; pitch 电压 10000 起步, RPM_LIMIT 400, SLEW 200。

## 交付形式
DJ_Motor.h/.c: +DJ3508_Send_All, +DJ6020_Send_All, +gim6020_pitch, 回调+0x206;
rc_dbus.h: +GMP_* pitch 参数组, +FRIC_* 摩擦轮参数组;
rc_dbus.c: 第5步改合并发送, +5b 摩擦轮状态机, 第6步改存volt_yaw, +第7步pitch, +第8步合并0x1FF。
旧 DJ3508_Send_I/DJ6020_Send_I 调用替换, 函数可删。
